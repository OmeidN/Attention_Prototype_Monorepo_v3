# Shared Metrics

Candidate metrics: Attempts, Opens, Sessions, Access Windows, Usage Minutes, Intentional Choices, Continue Choices, Goal Completion, XP, Streak, Attention Score, Estimated Time Reclaimed.

## Naming Rule
Use the most conservative accurate label. If an API identifies foreground episodes rather than launches, call them sessions. If it grants bounded access without exact session boundaries, call them access windows.

Do not finalize Attention Score until both platforms identify reliable signals.
