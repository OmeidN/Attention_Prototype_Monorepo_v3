# Milestone 12 — Reboot and OEM Stress Testing

## Goal
Test reboot, permission revocation, force stop, date rollover, low-power mode, rapid repeated access, Pixel if available, Samsung when available. Document force-stop behavior rather than bypassing platform rules.

## Acceptance Rule
Do not mark PASS from code alone. Run the required physical-device experiment, record evidence, then stop before the next milestone.
