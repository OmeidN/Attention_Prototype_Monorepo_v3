# P07 Scoring Weights

Local-only. Recomputed from `TodayEventLog` on ingest. Never Screen Time opens / Report.

| Action | XP |
|---|---|
| Never Mind (`intentional_choice`) | +10 |
| Continue | +0 |
| `access_window_end` with elapsed ≤ preferred window length | +5 short-window bonus |

## Daily goals

1. ≥1 Never Mind  
2. ≥3 Never Minds (stretch)  
3. ≤5 Continues (soft cap)  
4. ≤15 minutes access-window time  

## Streak

Consecutive local calendar days with ≥1 Never Mind. If today has none yet, streak can still count through yesterday.
