# AttentionAPITest — iOS

Native iOS feasibility prototype for the Attention intervention model, built against Apple's Screen Time APIs (FamilyControls, ManagedSettings, DeviceActivity).

Development is local: Apple silicon Mac, Xcode, physical iPhone over USB, paid Apple Developer Program membership. See `docs/DEV_ENVIRONMENT.md`.

Start with `milestones/MILESTONE_00_LOCAL_DEV_SETUP.md` and work in order. Every milestone from M02 onward requires physical-device evidence before it can be marked PASS — the Simulator does not implement Screen Time behavior. Record all results in `docs/TEST_RESULTS.md`.
